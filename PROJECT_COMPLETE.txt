  $ python3 app.py

STEP 2: Open in browser
  http://localhost:8888

STEP 3: Login
  Username: user
  Password: password123

STEP 4: Try a command

⚙️ TECHNICAL DETAILS
═══════════════════════════════════════════════════════════════════════════════

TECHNOLOGY:
  • Pure Python 3.7+ (zero external dependencies)
  • Built-in HTTPServer (http.server module)
  • No frameworks, no npm, no pip packages needed
  • Vanilla JavaScript (no React, Vue, Angular)
  • CSS only (no SASS/LESS)

ARCHITECTURE:
  • Single-file backend (app.py)
  • Stateless HTTP API (REST-like)
  • Session management with UUIDs
  • In-memory virtual file system
  • Per-user home directories

SECURITY:
  • No real system access (sandboxed)
  • Simple password validation
  • Session-based authentication
  • Safe for educational use
  • Input validation on commands

PERFORMANCE:
  • Responds in <50ms per request
  • Handles multiple concurrent users
  • Lightweight memory footprint
  • Scales for small group use
